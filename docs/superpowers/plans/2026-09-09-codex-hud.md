# Codex HUD Implementation Plan

> **For agentic workers:** Use subagent-driven development for isolated
> renderer/launcher work; integrate and verify in this session.

**Goal:** Deliver an installable local Codex HUD with live activity.

**Architecture:** Read rollout JSONL into a bounded session reducer, enrich with
Git metadata, and render in a separate terminal pane. Provide a tmux launcher
and native status-line configuration output.

**Tech Stack:** Node.js 20+, JavaScript ESM, node:test, optional tmux.

**Spec:** `docs/superpowers/specs/2026-09-09-codex-hud-design.md`

## Global Constraints

- Node.js 20+ ESM, zero npm dependencies, built-in `node:test`.
- No modifications to the Codex executable, credentials, or existing user config.
- No network access or model requests by the HUD.
- No private session content in fixtures.
- Missing usage stays unavailable.
